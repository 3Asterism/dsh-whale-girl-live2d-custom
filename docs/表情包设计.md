# 表情包与「有灵魂」场景设计

> 素材：**赤风RED**（<https://space.bilibili.com/356746604>）的「蓝色大肥鱼」表情包。版权归她所有，本项目只做非商业分发，见 [`AUTHORS.md`](../AUTHORS.md)。
> 代码入口：`assets/app/persona/stickers.js`（什么时候用哪张）、`assets/app/ui/sticker-pick.js`（选图与时长规则，纯函数）、
> `assets/app/ui/sticker.js` / `bubble.js`（加载与显示）、`assets/app/behavior/soul.js`（新场景）。

## 1. 目标

她说话时，台词**后面**跟一张对应的 GIF；有些时刻（深度思考、余额不足）**只丢一张图**就够了。
图要**懂梗**——按梗的真实含义用，不按字面；而且绝不能因为一张图把气泡拖长、长时间挂在页面上干扰干活。

## 2. 压缩：只存压好的，不存两份

原图 157 张 / 460MB（500×500、20ms/帧）。构建脚本 `tools/build-stickers.py`（需要 `pip install pillow`）只读取你指定的原图目录，**不拷贝原图**：

```
python tools/build-stickers.py "<原始 gif 目录>"
```

| 步骤 | 做法 |
|---|---|
| 挑选 | 只处理 `tools/stickers.curation.json` 里入选的 92 张（`id` + 原文件名 + 这张图的梗） |
| 裁边 | 取全部帧的透明包围盒，裁成方形，人物才占满画面 |
| 缩放 / 抽帧 | 96×96（显示 ≈44px，2× 高清）、25fps |
| 调色 | 63 色全局调色板 + 1 个透明色，不抖动（赛璐璐风格不需要） |
| 校验 | 单张 ≤210KB、总计 ≤12MB（现 10.5MB），超标直接失败；单圈 >2.6s 的剔除 |
| 输出 | `assets/stickers/<id>.gif` + `manifest.json`（**一圈时长在构建期测定**，运行时不解析 GIF） |

显示尺寸：台词气泡里 44px（约字号的 3.5 倍），只有一张图的小气泡里 56px；随 `--dshp-s` 缩放，下限 28px。

## 3. 时长：气泡由台词决定，图迁就气泡

> 强行播满整圈 → 短台词被拖长，气泡多挂在页面上；到点就砍 → 偶尔半圈被切。**选「不拖长」**，用三招压低被砍的概率：

1. **选图时按时长过滤**：只挑 `一圈 ≤ ttl + 400ms` 的图；没有够短的就换一张够短的，实在没有才不挂。
2. **极小吸附**：到点时当前圈只差 ≤400ms 就播完，才多等这一小会儿；否则直接收。
3. **兜底淡出**：没播完的随气泡一起淡出；气泡收起后摘掉 `<img>`（停掉解码）。

其余：每次显示都新建 `<img>`（从第 0 帧播）；`perform()` 的时序、脸部表情的 `ms` 一律不改；
常驻气泡（工具调用 / 开工 / 思考）里的图只播 2 圈（≤4s）就淡出，并且 20 秒内不重复配图；
独立表情包停留 `clamp(一圈+300ms, 1.8s, 3.2s)`；「正在思考」最长 10 秒、每一步只出现一次。
带按钮的提问气泡、流式回复、>100 字的长文本不挂图；`prefers-reduced-motion` 下整体不显示。

## 4. 选图：覆盖优先

绝大部分台词都该有图，只有实在没法适配才不配。优先级（`resolvePools`）：

`显式 sticker` → `显式 pool` → **事件**（台词 id / 表演 id）→ **台词里的括号动作词**（「（戴墨镜）」配墨镜）→ **情绪 mood** → **兜底池**

- 「近 90 秒用过」只影响偏好：候选都用过时选**最久没用**的（LRU），不会因此变成「不挂」。
- 一次性台词不节流；常驻气泡才用 `gapMs` 节流。
- `tools/test-stickers.mjs` 会检查**每一个台词 id 都映射了表情包**，新加台词忘了配会直接红。

## 5. 梗的语义（按梗用，不按字面）

| 表情包 | 梗 / 真实含义 | 用在哪 |
|---|---|---|
| 坐牢 | 中文 meme：被事情困住、反复折磨——**又失败了** | 连着第 2 次失败 / 同一轮报错 ≥3 次 |
| 停止工作 | Windows「已停止工作」弹窗＝崩了 | 第 1 次失败 |
| 一切都好 | This is fine：着火了还说没事 | 连着第 3 次以上失败、重试 3 次仍在硬撑 |
| 小丑 | 「小丑竟是我自己」：一厢情愿被打脸的自嘲 | **你拒绝了她的提议** |
| 要米 | 要饭卖惨，求投喂 | 钱包余额 **< 5 元**（CNY，每天最多一次） |
| 正在思考 | 头顶转圈的加载花 | **深度思考**（reasoning 增量），单独出现 |
| 带薪拉屎 | 上班借口如厕摸鱼（已证实的梗） | 工具跑太久（30s / 90s） |
| 跳舞(低皮质醇) | 低皮质醇：放松、没压力 | 顺利收工 / 下班 / 谷价 |
| 反转 | UNO 反转卡，把锅甩回去 | 重新生成、撤回输入 |
| 得分 0 / 10 | 打分牌 | 点踩 / 点赞、目标完成 |
| 拿走我的钱 | Shut up and take my money | 降价了 |
| 通知_提示×6 | 直播间打赏 / 关注提示 | 里程碑、羁绊升级 |

完整的 92 张与各自的梗见 `tools/stickers.curation.json`。**不收**：Bug、Popcat、Raid、六七、摇可乐、催眠、撬棍、枪、刀（暴力）、
烧 / 电风扇 / 睡觉 / 冒泡（全屏背景）、呆(贴纸)（写着「肥鱼」，违背「不能被叫胖」的人设）。

## 6. DSH 0.2.0-rc.2 里她能看见的事（宿主 `lib/events/slim.js` → 前端 `behavior/soul.js`）

会话事件（来自 DSH 安装包 `known-event-types`，共 64 种）里，这一版新接了：

| 事件 | 载荷（已核实） | 她的反应 |
|---|---|---|
| `model/selection` | `{provider, model, reasoningEffort?}` | 换成别家模型：吃醋（**不说品牌**）；换回 DeepSeek：欢迎回来；调推理强度 |
| `request/header` | `header.config.{provider, model, reasoningEffort}`（每次请求实际用的） | 同上；同一模型由宿主去重 |
| `sandbox/mode` | `{mode: 'read-only' \| 'workspace-write' \| 'danger-full-access'}` | 权限放到最大：紧张；只读：捂手 |
| `command/run` | `{commandId, name, args?, source}` | 接令（**只转 name，不转 args**） |
| `agent-preset/selected` | `{agentPreset}` | 换装 |
| `schedule/change` | `{operation: 'create' \| 'delete' \| 'dispatch', …}` | 新建 / 到点 |
| `tool/call` 名为 `ask_user_question` | — | 举牌提问，等 60 秒没回应就摇铃 |

另外：reasoning 增量（深度思考）、连续失败、approval 被拒、余额不足、你反复点「重新生成」、你发呆
（输入框写了一半停 45 秒 / 页面 2 分钟没动静，仅话痨档）。

**一个踩过的坑**：用户新建会话后先选模型再发话，这时宿主的「当前会话」还停在旧会话上，事件会被当成子代理的丢掉。
现在人新建的空白会话立刻成为当前会话，选择类事件对非子代理会话一律放行（子代理按 `origin` / `delegationDepth` 排除）。
前端另有一道 DOM 兜底：识别模型下拉里（带「搜索模型…」输入框的弹层）的点选。

## 7. 加一张新图

1. 把原图放进你的原图目录，在 `tools/stickers.curation.json` 里加一行（`id` / `src` / `meme`）；
2. `python tools/build-stickers.py "<原图目录>"`；
3. 在 `persona/stickers.js` 里把它挂到某个情绪 / 事件 / 括号动作词上；
4. `node tools/test-stickers.mjs`（数据与规则）、`node tools/smoke-stickers.mjs`（真浏览器，需先 `node tools/preview-server.mjs`）。
