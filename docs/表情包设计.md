# 表情包与「有灵魂」场景设计

> 素材：**赤风RED**（<https://space.bilibili.com/356746604>）的「蓝色大肥鱼」表情包。版权归她所有，本项目只做非商业分发，见 [`AUTHORS.md`](../AUTHORS.md)。
> 代码入口：`assets/app/persona/stickers.js`（什么时候用哪张）、`assets/app/ui/sticker-pick.js`（选图与时长规则，纯函数）、
> `assets/app/ui/sticker.js` / `bubble.js`（加载与显示）、`assets/app/behavior/soul.js`（新场景）。

## 1. 目标

她说话时，台词**后面**跟一张对应的 GIF；有些时刻（深度思考、余额不足、没人理她的时候）**只丢一张图**就够了。
图要**懂梗**——按梗的真实含义用，不按字面；而且绝不能因为一张图把气泡拖长、长时间挂在页面上干扰干活。
**原图 157 张一张不落**：每一张都挂在了至少一个场景上（`tools/test-stickers.mjs` 会检查，闲置一张就红）。

## 2. 压缩：只存压好的，不存两份

原图 157 张 / 460MB（500×500、20ms/帧）。构建脚本 `tools/build-stickers.py`（需要 `pip install pillow`）只读取你指定的原图目录，**不拷贝原图**：

```
python tools/build-stickers.py "<原始 gif 目录>"
```

| 步骤 | 做法 |
|---|---|
| 挑选 | 处理 `tools/stickers.curation.json` 里的全部 157 张（`id` + 原文件名 + 这张图的梗；可选 `opaque` / `speed` / `colors`） |
| 裁边 | 取全部帧的透明包围盒，裁成方形，人物才占满画面 |
| 缩放 / 抽帧 | 96×96（显示 ≈44px，2× 高清）、25fps；原图单圈 >2.7s 的可写 `speed` 加速（现在只有「吃甜甜圈」，4s → 2.5s） |
| 调色 | 63 色全局调色板 + 1 个透明色，不抖动（赛璐璐风格不需要）；色多帧多的写 `colors: 30`（或 40）减色（现在 7 张） |
| 校验 | 单张 ≤210KB、总计 ≤24MB（现 17.8MB），超标直接失败；单圈 >2.7s 的剔除 |
| 输出 | `assets/stickers/<id>.gif` + `manifest.json`（**一圈时长在构建期测定**，运行时不解析 GIF） |

显示尺寸：台词气泡里 44px（约字号的 3.5 倍），只有一张图的小气泡里 56px；随 `--dshp-s` 缩放，下限 28px。

## 3. 时长：气泡由台词决定，图迁就气泡

> 强行播满整圈 → 短台词被拖长，气泡多挂在页面上；到点就砍 → 偶尔半圈被切。**选「不拖长」**，用三招压低被砍的概率：

1. **选图时按时长过滤**：只挑 `一圈 ≤ ttl + 400ms` 的图；没有够短的就换一张够短的，实在没有才不挂。
2. **极小吸附**：到点时当前圈只差 ≤400ms 就播完，才多等这一小会儿；否则直接收。
3. **兜底淡出**：没播完的随气泡一起淡出；气泡收起后摘掉 `<img>`（停掉解码）。

其余：每次显示都新建 `<img>`（从第 0 帧播）；`perform()` 的时序、脸部表情的 `ms` 一律不改；
常驻气泡（工具调用 / 开工 / 思考）里的图只播 2 圈（≤4s）就淡出，并且 20 秒内不重复配图；
独立表情包停留 `clamp(一圈+300ms, 1.8s, 3.2s)`；「正在思考」最长 10 秒、每一步只出现一次。
带按钮的提问气泡、流式回复、>100 字的长文本不挂图；`prefers-reduced-motion` 下整体不显示。

## 4. 选图：覆盖优先 + 单发图

绝大部分台词都该有图，只有实在没法适配才不配。优先级（`resolvePools`）：

`显式 sticker` → `显式 pool` → **事件**（台词 id / 表演 id）→ **台词里的括号动作词**（「（戴墨镜）」配墨镜）→ **情绪 mood** → **兜底池**

- 「近 90 秒用过」只影响偏好：候选都用过时选**最久没用**的（LRU），不会因此变成「不挂」。
- 池子里写重复的 id 就是加权（`kwFat` 里 `fatnote` 占大半）。
- 一次性台词不节流；常驻气泡才用 `gapMs` 节流。
- `tools/test-stickers.mjs` 会检查**每一个台词 id 都映射了表情包**，新加台词忘了配会直接红。

**单发图（v0.6.7）**：`perform({ solo: '池名' })`——不带台词，只在小气泡里丢一张图，停留时间由图自己决定。池子在 `persona/stickers.js` 的 `SOLO_STICKER`。
用在「没人理她的时候」「深度思考」「睡着」这类话反而多余的时刻。

**不再回避**（v0.6.7 起）：之前不收的 Bug / Popcat / Raid / 六七 / 摇可乐 / 催眠 / 撬棍 / 枪 / 刀、烧 / 电风扇 / 睡觉 / 冒泡（整幅不透明，用 `opaque` 圆角显示）、以及写着「肥鱼」的呆(贴纸)，现在都入选了。

## 6. DSH 里她能看见的事

宿主 `lib/events/slim.js` 把会话事件裁成紧凑消息 → 前端 `behavior/sev.js` / `soul.js` / `events.js`。DSH 0.2.0-rc.2 共 64 种会话事件，目前接了：

| 事件 | 载荷（已核实） | 她的反应 |
|---|---|---|
| `model/selection` / `request/header` | `{provider, model, reasoningEffort?}` | 换成别家模型：吃醋（**不说品牌**，配刀）；换回 DeepSeek：欢迎回来；调推理强度 |
| `sandbox/mode` | `{mode}` | 权限放到最大：紧张 + 撬棍；只读：捂手 / 胶带 |
| `command/run` | `{commandId, name, args?, source}` | 接令（**只转 name，不转 args**） |
| `agent-preset/selected` | `{agentPreset}` | 换装 |
| `schedule/change` | `{operation}` | 新建 / 到点（扩音器） |
| `compaction/start` · `prune` · `summary` · `end` | 无需载荷 | **压缩全流程**：开始（拿本子）→ 清理旧工具结果（喷剂 / 垃圾桶）→ 写摘要（做小抄）→ 拖太久（20s 补一句）→ 结束；点 DSH 的「压缩」按钮也当场有反应 |
| `tool-workflow/run-start` · `run-end` | `{runId, name}`（**只转启停，不转名字**） | Raid 举牌「分身出击」/ 清点人数 |
| `team/member` · `team/task` | 只取「有动静」 | 举喇叭（话痨档，45s 冷却） |
| `session/title` | `{title}`（**不转标题内容**） | 起好名字了：贴标签（话痨档） |
| `tool/call` 名为 `ask_user_question` | — | 举牌提问，等 60 秒没回应就摇铃 + 指着你 |
| `tool/result` 带耗时 | `ms` | 慢工具（≥30s，等人回话 / 分身 / 工作流除外）回来：跳散味舞 |
| `turn/end` 带 tokens / 耗时 | — | ≥80 万 token 着火收工；≥15 分钟电风扇收工 |

另外：reasoning 增量（深度思考）、连续失败、approval 被拒、余额不足 / 回来、你反复点「重新生成」、你发呆
（输入框写了一半停 45 秒 / 页面没动静，仅话痨档）。

**界面操作**（`persona/page-actions.js`，DOM 点击委托，只读）：新建会话、设置、终端、文件、停止、复制、重新生成、**压缩上下文、附件、分享、导出、搜索、语音、置顶、重命名、分叉、撤销、编辑、帮助**。
标签是中英双语的最佳猜测，认不出就不触发、无副作用；`DSHPet.page.recent()` 能看到最近点过的标签，缺的往表里补一行。

**一个踩过的坑**：用户新建会话后先选模型再发话，这时宿主的「当前会话」还停在旧会话上，事件会被当成子代理的丢掉。
现在人新建的空白会话立刻成为当前会话，选择类事件对非子代理会话一律放行（子代理按 `origin` / `delegationDepth` 排除）。
前端另有一道 DOM 兜底：识别模型下拉里（带「搜索模型…」输入框的弹层）的点选。

## 7. 没人理她的时候：单发图

主人一阵子没动键鼠、agent 也没在干活，她自己找点事做（只丢图，不说话；AMBIENT 优先级，低性能档不出现，有话的气泡里不插）：

| 时刻 | 出什么 |
|---|---|
| 安静满 60 秒（`soul.js` 静置阶梯，一段安静只出一次） | **打游戏**（摸鱼） |
| 待机大脑随机（~10%，要求安静 ≥40 秒，每 45 秒最多一次） | 按时间 / 心情选池：深夜犯困（催眠 / 打瞌睡）、饭点馋（碗筷 / 甜甜圈）、心情好跳舞 / 弹吉他、低落发呆，平时是打游戏 / 吉他 / 唱歌 / 画板 / 驾驶 / 可乐 / 冒泡 / 魔性舞…… |
| 3 分钟没动静（`sleepAfterMs`） | 趴下睡着：睡觉 / UU / 准备阶段（先打哈欠 = 打瞌睡） |

## 8. 关键词反应（用户原话，本地匹配，不上传）

只对「口语化的短消息」生效（粘贴的日志 / 代码 / 堆栈不算）。更具体的梗排在前面：

- **反差萌**：说她「胖 / 肥鱼」→ 台词死活不认，图却是「肥鱼」便利贴。
- **妈妈梗**：夏亚那句「能成为我母亲的女性」、バブみ / 妈妈味、奶妈、直接叫妈妈 / ママ——见 [人设与台词规范](人设与台词规范.md) 的「小只妈妈」。
- 日常词：`bug / 修复`（拍虫）、`67 / 六七`（单独发才算）、`摸鱼`、`涨价`、`哈哈`、`可乐 / 奶茶`、`唱歌 / 吉他`、`生日 / 红包`、`截图 / 自拍`、`闭嘴 / 安静点`（贴胶带）、`睡觉 / 熬夜`（催眠）、`好热`（电风扇）。

## 9. 表情包图鉴同步

图鉴的「全集」由宿主启动时读 `assets/stickers/manifest.json` 注入（上报按清单校验），所以总数自动是 157。但扩容有三个要处理：

1. **老存档不能显示「梗大全 ✓」却只有 92 张**：里程碑按总数的比例（10% / 30% / 60% / 100%）重算，扩容后没达标的会被摘掉，重新达成才再亮。
2. **奖励只发一次**：新增 `albumPaid` 记账——领过的里程碑再次达成只庆祝（xp 0，事件带 `again: true`），不重复发羁绊值；旧存档没有这个字段就按「之前达成的都领过」迁移；《图鉴集齐》回忆已经解锁的不丢。
3. **UI**：已收录的排前面，没见过的只露 8 个「？」预告 + 一块「+N」，免得 157 格铺成一面墙；小 GIF 等分区展开了才加载（`loading=lazy`）。

单发图（`solo`）也走同一条上报路径，所以待机时她丢的每一张新图都会收进图鉴。

## 10. 加一张新图

1. 把原图放进你的原图目录，在 `tools/stickers.curation.json` 里加一行（`id` / `src` / `meme`）；
2. `python tools/build-stickers.py "<原图目录>"`；
3. 在 `persona/stickers.js` 里把它挂到某个情绪 / 事件 / 括号动作词 / 单发池上（否则 test-stickers 会说「闲置」）；
4. `node tools/test-stickers.mjs`（数据与规则）、`node tools/smoke-scenes.mjs` 与 `node tools/smoke-stickers.mjs`（真浏览器，需先 `node tools/preview-server.mjs`；**改了 `lib/` 要重启预览服务器**，它是常驻进程）。
