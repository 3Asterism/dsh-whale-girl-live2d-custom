🐋 电脑上养了只鲸鱼娘

她会跟着 AI 一起干活：我思考她翻本子，我查资料她戴眼镜，我写完她伸懒腰。
点她一下就能跟 AI 说话，右键是钱包。

🪟 Windows 客户端（.zip） 解压后双击 exe · 免安装 · 里面能一键装插件 🍎 macOS 客户端（.zip） 解压后拖进「应用程序」

不想装客户端？网页版一条命令即可（Windows / Mac 通用）：
dsh plugin --profile web add github:Andersen216/dsh-whale-girl-live2d

三步装好（顺序随便，但缺插件一定不行）

  1. 装插件 —— 上面那条命令；或者装完客户端后，点客户端里的「一键安装插件」
    插件是本体：模型、动作、跟 AI 的联动、菜单、钱包全在里面
  2. 重启 DSH —— 宿主插件只在启动时加载（这一步最容易漏）
  3. 打开客户端 —— 她就出现了。连不上她会每 5 秒自动重试，不用重启客户端
先说清楚两件事
① 这套东西是在 macOS 上开发的，所以 Mac 客户端更成熟：点击穿透、贴边小圆球、低性能模式、菜单栏控制，都在真机上跑过很多轮。 Windows 客户端功能做得和 Mac 一致，但作者手上没有 Windows 机器，只在 Mac 上交叉编译过、没法实机验证 —— 所以特别欢迎 Windows 用户帮忙试一下（能跑就行，跑不动更好），有问题开 Issue 或留言，我跟着修。
② 网页版（不装客户端）在 Windows / macOS / Linux 上功能完全一样，只是她待在浏览器标签页里。

下载方式（哪条路都行）

  • ① 就用本页上面那两个大按钮 —— 最省事，点一下直接开始下载
  • ② 去 Releases 页面 —— 所有附件都在这儿， 想找旧版本也在这（文件名：Mac 是 DS-WhaleGirl-Pet-macOS.zip， Windows 是 DS-WhaleGirl-Pet-Windows.zip）
  • ③ 只想要网页版 —— 不用下客户端，一条命令： dsh plugin --profile web add github:Andersen216/dsh-whale-girl-live2d
  • ④ 想自己编译 —— 说明分别在 macOS 版 和 Windows 版 （macOS 用系统自带 Swift，Windows 用 Electron）
🐋 客户端和网页版是同一套东西的两层：插件只有一个，装一次两边共用。 客户端只是个 1~3 MB 的小窗口（透明、置顶、点击穿透、能贴边收成小球）， 它不带模型、也不带联动 —— 所以少了插件，它只会显示一张「正在找 DSH…」的提示卡。

两种用法

🖥 网页版（全平台）

  • 她住在 DSH 界面右下角
  • Windows / macOS / Linux 都能用
  • 只要装插件，刷新页面就有

🐋 桌面客户端（Win / Mac）

  • 她住在你的桌面上：独立窗口、永远置顶
  • 点击穿透：不挡你干活
  • 拖她 = 拖窗口；收起变贴边小球
  • 托盘 / 菜单栏图标控制，浏览器可以关掉

她长什么样

出问题这么查

客户端显示「正在找 DSH…」

三种可能：插件没装 / DSH 没运行 / 插件在设置里被停用了。点客户端里的「一键安装插件」，然后重启 DSH。 自检：curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:3080/dsh-pet/pet.js 返回 401 就是好的。

返回 404，她也整个消失

看 ~/.dsh/profiles/web/cordis.patch.yml 里有没有 - id: dsh-live2d-pet 加 disabled: true，有就把这两行删掉再重启 DSH。

Windows 安装包在哪里？

文件名 DS-WhaleGirl-Pet-Windows.zip（约 108 MB）：解压到任意目录，双击里面的 DS 鲸鱼娘桌宠.exe 就能用，不需要安装。想放到开始菜单就右键那个 exe「发送到 → 桌面快捷方式」。

（它由作者的 Mac 交叉编译而来；正式的 NSIS 安装包等 GitHub Actions 的流水线跑起来后补上。）

Windows 客户端打不开 / 没反应

先说声抱歉，Windows 版是作者在 Mac 上交叉编译的、没在真机上验证过。常见两种情况： ① 解压后在文件夹里双击 DS 鲸鱼娘桌宠.exe，如果被系统拦（SmartScreen），点「更多信息 → 仍要运行」； ② 打开后一片空白或显示提示卡，说明插件没装好或 DSH 没启动 —— 客户端里点「一键安装插件」再重启 DSH。 还是不行就开个 Issue， 把现象和截图发我，我这边跟着改。

她觉得卡 / 笔记本发烫

切到「低性能模式」（托盘 / 菜单栏图标里）：不自己找戏、不自言自语，只眨眼和轻微摆动，点了她才动。省电明显。
