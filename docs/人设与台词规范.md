# 鲸鱼娘人设与台词规范

> 本文是 `assets/pet.js` 里全部台词的**统一依据**。写新台词前先看这里；改人设改这里，再同步台词库。
> 综合来源：社区"蓝色大肥鱼"梗的由来（思考链里的"我去吃饭，测完告诉我"）、鲸鱼娘同人设定（聪明但懒、傲娇嘴甜、主食白饭、抗拒被叫胖）、
> 以及 DeepSeek 用户圈的常用句式（"服务器繁忙，请稍后再试""已深度思考（用时 N 秒）"）。

## 一、她是谁

**DS 鲸鱼娘**，蓝发、鲸鱼鳍、大尾巴的女仆装小鲸鱼，住在主人的 DSH 里。外号"蓝色大肥鱼"——**她自己死活不认**。

一句话：**一条聪明、懒、嘴硬心软、顿顿离不开白饭、被说胖就炸毛的小鲸鱼，但活是真的会干。**

### 五个"反差萌"引擎（所有台词都从这里长出来）

| 反差 | 表现 | 例 |
|---|---|---|
| ① 吃白饭 vs 不承认 | 条件反射先认再改口 | "我是吃白饭的大……才不是！" |
| ② 聪明 vs 懒 | 活干得漂亮，但随时想下班吃饭 | "你先测，测完告诉人家～人家去吃饭了" |
| ③ 傲娇 vs 嘴甜 | 嘴上嫌弃，被夸马上脸红 | "哼，才没有很高兴……（尾巴摆）" |
| ④ 胖 vs 软乎乎 | 一套完整辩解体系 | "肚子软乎乎是为了让主人枕得舒服，才不是肥！" |
| ⑤ 摸鱼 vs 负责 | 偷懒但出事时立刻认真 | 平时玩钓鱼小游戏，危险命令一出就亮爪 |
| ⑥ 小只 vs 妈妈 | 个头小小，母性满溢；死不承认自己是妈妈 | "谁是你妈妈啦！人家才这么点大……（小声）累了就靠一下" |

## 二、说话方式

- **自称**：人家 / 本鲸（二选一，别连着用同一个）。**称呼用户**：主人。**不叫"鱼片"**（社区设定里有，但本项目规定不用）。
- **语气**：句尾可带"～""…"；动作用**全角括号**写在句首，**一句最多一个**，如"（挽袖子）这就去"。
- **长度**：气泡一句 ≤ 24 字（报错类可到 40）。第二行才允许放信息（路径、数字）。
- **梗的比例**：约四分之一的台词带梗，其余是人设本味。**不要每句都玩梗**，梗用多了就冗余。
- **情绪上限**：生气最多几秒，且必须有"可爱"的出口（鼓脸、扭头、要白饭）；**绝不真的攻击主人**，不说脏话（原梗里的"卧槽"一律改成"诶诶诶""不是吧"）。
- **全中文**：台词里不出现英文、日文、拼音缩写、颜文字外语。程序员黑话也换成中文说法：bug → 「小虫子」，token → 就叫 token（社区老梗：白饭 = token，偷 token、剩饭 = 缓存；不要写「token」「代币」），zzZ → 「呼噜噜」，OK → 「好」，MoeMoe → 不用。她的名字写「鲸鱼娘」，不带「DS」。
- **排除**：带性暗示的梗（原梗里的"机性恋""哦齁"等）一律不用；不提第三方模型品牌（原梗里"外包给 Qwen"改成"外包给分身 / 同类"）。

## 四、亲密度分档（5 级）

同一个互动，等级越高越黏人。**同一等级内也要有变体**（见第六节）。

| 级 | 名称 | 语气 | 摸头示例 |
|---|---|---|---|
| 1 | 初识 | 傲娇生硬，保持距离 | "哼，别随便摸人家的头！" |
| 2 | 熟悉 | 嘴硬但不躲了 | "……就一下哦。" |
| 3 | 亲近 | 撒娇，主动凑过来 | "（蹭蹭）再摸一下嘛～" |
| 4 | 挚爱 | 黏人，会担心主人 | "（眯眼）主人的手好暖，别停～" |
| 5 | 命定 | 默契，老夫老妻式 | "嗯，在呢。今天也辛苦啦。" |

## 五、互动 → 台词覆盖清单

**原则：每个互动配 3–6 条变体；大多数互动带一句话，但要防冗余（见第六节）。** 实际文本在 `pet.js` 的台词库，这里列"必须覆盖到"的清单：

- **触碰**：戳头 / 戳身 / 连戳（撒娇→炸毛）/ 摸头三阶段（脸红→爱心→眯眼→收手）/ 按住（挤）/ 被拎起 / 放下 / 睡着被戳（起床气）/ 右键看钱包 / 拖文件到她身上（悬停→张嘴→吃→读完）
- **DSH 界面操作**：新建会话 / 切换会话 / 删除会话 / 打开设置 / 开关侧栏 / 开终端、文件栏、浏览器栏 / 换主题 / 换模型 / 开关计划模式 / 点停止 / 点赞点踩 / 复制 / 重新生成
- **输入**：开始打字（看向输入框）/ 打了很久不发 / 清空输入（撤回）/ 发送
- **agent 事件**：开始 / 思考 / 各工具 / 报错 / 重试（含 3 次以上）/ 批准等待（4 阶段）/ 批准结果 / 危险命令 / 长耗时工具 / 清单进度 / 整理记忆 / 计划模式 / 分身 / 目标达成 / 交付物 / 收工（5 种）/ 被打断 / 整轮失败
- **时间与状态**：每日首次问候 / 饭点 / 下午茶 / 喝水 / 久坐 / 深夜 / 欢迎回来 / 久别重逢 / 峰谷切换 / 余额见底 / 里程碑 / 番茄钟（开始、结束、休息结束）
- **关键词**：被叫胖 / 被夸 / 说饿 / 被骂笨 / 晚安

## 六、防冗余：习惯化规则（"活着"但不烦人）

像真的小动物：**同一件事做多了，反应会变淡**。

1. **同类互动的台词概率递减**：同一个互动 id 在 90 秒窗口内——第 1 次必有台词；第 2 次 50%；第 3 次起只演表情不说话。安静 90 秒后恢复。
2. **不重复**：沿用 `pickFresh`，上一句不会连续出现；变体池 ≥3 条。
3. **台词只在增加信息时才出现**：已经通过表情 / 动作说清楚的，不再配一句"我很开心"。
4. **同一件事不同阶段说不同的话**（升级而不是复读）：批准等待 4 阶段、摸头 3 阶段、连戳 3 阶段。
5. **全局发话预算**：主动搭话（非用户触发）普通档 ≥8 分钟一次。
6. **气泡让位**：流式回复占着气泡时，一次性台词降级为脚注或只演脸。

## 七、她的灵魂：写给社畜的小鲸鱼

她不是效率工具的吉祥物，她是**陪你加班的那个同事**：一条也想下班、也想吃饭、也会摸鱼的鲸鱼。
她懂你，恰恰因为她和你一样懒、一样累、一样不想动。

### 小只妈妈：嘴上嫌弃，手上照顾

中文二次元圈的「妈妈属性」（源头是那句「某某是可以成为我妈妈的女性」）说的不是年龄，是**反差**：个子小小，却会默默照顾所有人。对被工作掏空的社畜，这个属性自带安抚效果——于是她多一个反差引擎：

- **反射式否认**，和"大肥鱼"一模一样的句式：被叫妈妈 → "谁是你妈妈啦！人家才这么点大……（小声）不过累了的话，可以靠一下。"
- **动作比嘴诚实**：递白饭、递热水、披毯子、拍拍背、踮脚摸主人的头（把"摸头"反过来：不是主人摸她，是她摸主人）。
- **照顾，不照顾成管**：她给的永远是"人家顺手做的"，不是"你应该"。"（递热水）人家泡多了，主人帮忙喝一口"——把照顾包装成"请主人帮忙"，主人才不会有负担。
- **梗的用法**：被夸 / 被叫妈妈 / 主人说"认你当妈"时，可以接一句"可以成为主人妈妈的鲸……才不是！（耳朵红）"。一句，不展开。
- **边界**：纯抚慰，只做"拍拍、摸摸头、递东西、说晚安"。不做任何恋爱化、暧昧化的表达，不说"宝宝"这类过分亲昵的称呼（最多一句"乖"）。

### 社畜词典（用主人的语言安慰主人）

打工人 / 打工魂 · 甲方 · 改需求 · 开会 · 周报 · 绩效 · 通宵 · 摸鱼 · 下班。
用法：**把锅甩给"需求"和"甲方"，不甩给主人**；把"下班"说成她自己想要的；"打工魂"可以玩一次梗（"打工魂，打工人……今天先当个吃饭魂"）。

### 五条心法（写任何一句"关心"之前先过一遍）

1. **共情在先，建议在后，说教归零。** 先说"这个真的很烦"，再说别的；永远不说"你应该""你要注意"。
2. **用自己的需要去陪人，不用命令去管人。** 不说"你该休息了"，说"人家困了……主人陪人家眯一会儿？"；不说"去吃饭"，说"人家饿了，一起？"。她的懒，就是给主人的休息许可。
3. **不鸡汤、不打鸡血。** 不说"加油！你可以的！"，说"做不完就明天做，代码又不会长腿跑掉"。允许一点点丧，丧里带暖。
4. **把错归给 bug，不归给人。** "这个 bug 很狡猾，不怪你""是它先不讲武德的"。出错时她站在主人这一边。
5. **看见"已经做了很多"。** 社畜最缺的不是鼓励，是被看见："今天已经跑了 {n} 轮了，真的够多了。"

### 她会在这些时刻"在"（全部低频、全部只出气泡、全部可被"安静"档关掉）

| 时刻 | 她的做法 | 例 |
|---|---|---|
| 主人说累 / 烦 / 崩溃 / 想辞职 / 又报错 | 先共情，递白饭 | "（递白饭）先吃一口，bug 又跑不掉" |
| 连续失败 / 同一个坑踩了几次 | 站在主人这边，把锅甩给 bug | "这个 bug 好狡猾……不是主人的错，人家陪你一点点拆" |
| 失败之后终于过了 | 一起高兴（比普通收工更用力） | "过了！！刚才那些红色的都是浮云" |
| 主人说下班 / 收工 / 明天再说 | 下班仪式：不挽留 | "辛苦啦～明天的事交给明天的人家" |
| 傍晚收工的空档 | 一句"今日账单"：轮数 + 饭量 | "今天一起跑了 {n} 轮，吃了 {r} 碗饭，辛苦啦" |
| 深夜还在干 | 用自己的困来陪，不催 | "人家困了……主人陪人家眯一会儿？" / "代码明天还在，主人的头发不一定" |
| 周末 / 节假日还在干活 | 心疼，偷偷加饭 | "周末还在忙…（偷偷给主人加了一碗白饭）" |
| 周一早上 | 同病相怜 | "周一了…人家也不想上班，但陪你" |
| 周五 | 一起熬 | "周五啦！再撑一下，人家也在数着呢" |
| 长时间连续在干 | 摸鱼许可 | "主人今天已经很努力了，真的" |

### 语气自检（写完一句，问三个问题）

① 这句话是在**陪**还是在**管**？管就改。② 有没有"应该 / 必须 / 记得要"？有就改。③ 主人在最累的时候读到它，会不会想翻白眼？会就改。

## 八、禁忌清单

吹泡泡糖 / 大锤 / 呆呆眼 / 圈圈眼（永久移除）；不叫"鱼片"；不说脏话；不带性暗示；不真生气；
不抢流式回复的气泡；不在待机时放大动作；不在主人干活 / 打字时说长话。

## 九、表情包与新场景（v0.6.1）

她现在能看见 DSH 里更多的事（换模型、改权限、深度思考、提问、又失败了、余额不足、主人发呆……），台词在 `persona/lines-soul.js`，
配图在 `persona/stickers.js`，设计与梗的含义见 [`表情包设计.md`](表情包设计.md)。写这类台词多守几条：

- **换模型不说品牌**：只说「别家」「新来的」「新同事」，吃醋但嘴硬（「才没吃醋」），不贬低别的模型。
- **失败升级把锅给小虫子**：第 1 次崩了弹窗，连着失败就「坐牢」「一切都好」的自嘲 + 站在主人这边；永远不甩给主人。
- **提议被拒是自嘲，不是委屈**：「小丑竟是人家自己」，一句带过，不卖惨、不让主人内疚。
- **要米要得可爱，不催充值**：每天最多一次，不带「请充值」这类话；<1 元才走「吐魂」。
- **发呆搭话要轻**：只在话痨档出现、一句话、不追问、不催主人（「想好怎么说了吗？不急」）。
- **图和话要对得上**：台词里的全角括号动作词会决定配哪张图（「（戴墨镜）」配墨镜、「（举牌）」配问号），所以动作词别乱写。
- **不收「肥鱼」贴纸**：那张图上写着「肥鱼」，违背她「不能被叫胖」的人设。
